# 高稳智能体 · 5GC 数字孪生指挥中心（展会演示前端）

面向通讯展会大屏的**沉浸式指挥中心**演示前端,独立于旧 `frontend/`(全新设计、未参考旧代码)。
单一全屏视图,自动循环播放「高稳智能体」三 Agent 闭环故事:数字孪生(网络本体)+ 大脑架构(智能体),
含仿真 → 异常检测 → 置信度路由 → 推理根因 → 执行恢复 → 网络恢复 → 评估优化的完整动画。

## 快速开始

```bash
cd frontend-show
npm install
npm run dev        # → http://localhost:5174  (自动循环播放)
```

构建 / 类型检查:

```bash
npm run build      # tsc --noEmit && vite build  → dist/
npm run lint       # tsc --noEmit
```

> 默认 **DEMO 模式**:内置取自真实 `storage/cases` 的样本数据,确定性自动播放,**不依赖后端/LLM**,展会现场 100% 可靠。
> 顶栏可切 **LIVE 模式**:轮询后端 `/health`,需后端运行(见下)。

## 操作

- **播放/暂停 ❚❚ / ▶** · **变速 0.5× / 1× / 2×**
- **场景切换** `A` 全域 gNB 故障(WORKFLOW·成功) / `B` AMF_3 单点(GUIDED·部分) / `C` 用户面链路(EXPLORATION·失败)
- **底部时间轴**:点击任意阶段跳转;白色播放头显示全局进度,自动循环
- **右侧详情面板**:随阶段自动切换(生成校验 / KPI 遥测 / 置信度 / 推理链 / 恢复 / 评估)

## 故事板 8 阶段(确定性自动循环)

| # | 阶段 | 数字孪生(本体) | 大脑(智能体) |
|---|------|----------------|--------------|
| 0 | 网络就绪 | 全网绿色,数据流粒子,KPI≈99.8% | 三 Agent 待命 |
| 1 | 数据生成 | 拓扑逐层生成,UE 接入 | Agent1 · 5 项 LLM 校验灯 |
| 2 | 异常检测 | 目标 NE/边矩形下跌,告警脉冲 | 检测器扫描→触发感知 |
| 3 | 置信度评估 | 受影响区高亮 | Agent2 · 加权子分 + 路由徽章 |
| 4 | 根因推理 | 工具调用反向高亮拓扑 | Agent Loop · 推理链收敛 |
| 5 | 执行恢复 | 隔离/重路由/主备切换 | 下发恢复策略,自愈中 |
| 6 | 网络恢复 | 节点/边回归绿色,KPI 回升 | 恢复确认 |
| 7 | 评估优化 | — | Agent3 · P/R/F1 + 推理质析 + 反馈回流 |

## 数据保真

所有内置数值忠实复刻真实系统区间:基线 success_rate 0.997~0.999、故障期 0.85~0.97、阈值 0.995、
置信度加权公式(`pattern×0.40 + severity×0.20 + temporal×0.15 + spatial×0.15 − ambiguity×0.10`)、
阈值 0.7/0.3、5 项校验、4 轴推理质析。拓扑取自真实 `case_001/topo.txt`。

> **关于"恢复动作"**:真实系统闭环为 诊断→评估→建议,**无执行器**(`DiagnosisResult` 无恢复字段)。
> 本前端按确定性脚本合成「下发恢复策略→网络自愈」一幕(隔离 / 重路由 / 主备切换),用于完整叙事,
> 对应数字孪生的可视化叠加,不伪造后端行为。

## LIVE 模式(可选,接真实后端)

需后端三处**增量**改动(已在本仓库完成):

1. `api/app.py` CORS 放行 `http://localhost:5174`
2. `GET /api/v1/generation/cases/{id}/files` 返回用例原始文件(原接口仅返回 `files:bool`)
3. Agent 的 `progress_callback` 桥接到 WebSocket `/ws/updates`(`api/routes/websocket.py::make_ws_callback`)

```bash
# 后端(另一终端)
python -m uvicorn api.app:app --port 8000
# 前端切到 LIVE 模式 → 顶栏显示后端连接状态
```

## 技术栈

React 18 + TypeScript + Vite 5 + Framer Motion。数字孪生为手写 SVG(节点按数据流分层布局、
沿路径运动的数据流粒子、KPI 驱动的健康着色、告警脉冲、根因准星、恢复叠加)。
