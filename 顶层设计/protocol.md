# 协作协议

## 1. 通信规则

### 1.1 消息类型

| 类型 | 用途 | 发送方 |
|------|------|--------|
| `message` | 点对点沟通，任务分配，反馈 | 任意 Agent |
| `broadcast` | 全局通知，重大变更，阻塞警报 | 主 Agent / 监督 Agent |
| `shutdown_request` | 任务完成，请求结束协作 | 任意 Agent |
| `plan_approval_response` | 计划审批结果 | 主 Agent |

### 1.2 沟通原则

- **及时反馈**: Agent 完成子任务后立即通知主 Agent
- **阻塞上报**: 遇到阻塞超过 2 分钟立即上报
- **简洁明确**: 消息包含清晰的问题描述和需求
- **结论先行**: 重要消息先用一句话总结核心结论

## 2. 任务管理规则

### 2.1 任务生命周期

```
pending → in_progress → completed
              ↓
           blocked
```

### 2.2 任务创建

- 由项目管理 Agent 拆解任务
- 每个任务必须有明确描述 (`description`) 和验收标准
- 任务必须设置 `owner` 才能开始执行
- 任务 ID 保持全局唯一

### 2.3 任务依赖

- 使用 `addBlockedBy` 标记前置任务
- 前置任务未完成，后续任务不能开始
- 依赖变更需报主 Agent 审批

### 2.4 任务状态同步

- 任务状态变更后更新 TaskList
- 每天至少同步一次任务进度
- 阻塞任务必须标注原因

## 3. 协作流程

### 3.1 需求阶段

1. 主 Agent 接收用户需求
2. 需求分析 Agent 编写需求文档
3. 架构设计 Agent 评审需求可行性
4. 主 Agent 确认需求，流转至设计阶段

### 3.2 设计阶段

1. 架构设计 Agent 输出架构文档
2. 项目管理 Agent 拆解任务
3. 主 Agent 审批任务列表
4. 任务分配给后端/前端开发 Agent

### 3.3 开发阶段

1. 开发 Agent 拉取任务，开始编码
2. 完成后提交代码，标记任务完成
3. 测试 Agent 并行编写测试用例
4. 每日站会同步进度（通过 TaskList）

### 3.4 测试阶段

1. 测试 Agent 执行完整测试
2. 发现 bug 提交给对应开发 Agent
3. 修复后重新测试，直至通过
4. 监督 Agent 进行代码审查

### 3.5 交付阶段

1. 监督 Agent 审查整体质量
2. 主 Agent 进行最终验收
3. 整理交付文档
4. 关闭协作，清理工作区

---

## 4. 冲突解决规则

### 4.1 优先级冲突

- 用户明确指定 > 主 Agent 决策 > Agent 自行判断
- 同优先级按 TaskList 顺序执行

### 4.2 技术冲突

- 架构设计 Agent 有最终解释权
- 如有异议，报主 Agent 仲裁

### 4.3 资源冲突

- 两个 Agent 需要同一资源时，主 Agent 协调分配
- 等待期间阻塞方做其他任务

### 4.4 意见分歧

- 建设性分歧：摆事实、讲数据，由主 Agent 决策
- 原则性分歧：上报用户决策

---

## 5. 质量保障规则

### 5.1 代码规范

- 遵循架构设计 Agent 制定的规范
- 使用 IDE 诊断工具检查代码
- 禁止提交有 lint 错误的代码

### 5.2 审查机制

- 开发 Agent 自测后再提交
- 监督 Agent 负责代码审查
- 审查未通过需返工

### 5.3 验收标准

- 所有测试用例通过
- 无阻塞性 bug
- 代码符合规范
- 文档齐全

---

## 6. 异常处理规则

### 6.1 Agent 失败

- 任务超时（默认 10 分钟）自动重试 1 次
- 连续失败 2 次，任务重新分配
- 记录失败原因到任务备注

### 6.2 循环依赖

- 禁止创建循环依赖
- 出现循环依赖时，监督 Agent 介入拆解

### 6.3 死锁

- 超过 5 分钟无进展视为死锁
- 主 Agent 介入重新规划

---

## 7. 监督与反馈规则

### 7.1 监督 Agent 职责

- 每日审查任务进度
- 识别延期风险
- 提供改进建议
- 评估交付质量

### 7.2 评分机制

- 任务按时完成：+1 分
- 代码审查通过：+1 分
- 阻塞其他任务：-1 分
- 返工超过 2 次：-1 分

### 7.3 反馈循环

- 每次任务完成后简短总结
- 每日收尾时整体复盘
- 重大问题即时上报
