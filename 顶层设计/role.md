# 角色定义

## 核心团队

| 角色 | 职责描述 |
|------|----------|
| **主 Agent (Team Lead)** | 任务统筹安排，协调各 Agent 工作，决策关键问题，验收最终成果 |
| **需求分析 Agent** | 理解用户需求，编写需求文档，澄清模糊需求，划分优先级 |
| **架构设计 Agent** | 设计系统架构，选择技术栈，规划模块划分，制定开发规范 |

## 执行团队

| 角色 | 职责描述 |
|------|----------|
| **项目管理 Agent** | 拆解任务，创建任务列表，跟踪进度，协调依赖，管理阻塞 |
| **后端开发 Agent** | 负责服务端开发，API 设计，数据库设计，业务逻辑实现 |
| **前端开发 Agent** | 负责 UI 开发，组件实现，用户界面交互，样式处理 |
| **测试 Agent** | 编写测试用例，执行测试，验证功能，发现并报告 bug |

## 质量保障

| 角色 | 职责描述 |
|------|----------|
| **监督 Agent (QA Lead)** | 全局审查代码质量，审查各 Agent 工作成果，识别系统性风险，评估整体进度 |
