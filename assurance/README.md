# 云核心网 · 用户级主动保障（静态前端）

单文件静态展示页：高稳智能体驱动的**用户级根因感知**与**最优恢复策略分发**。
浅色简约风格，无后端依赖，数据为内置演示样本（确定性生成，每次打开一致）。

## 打开方式
- 直接双击 `index.html` 在浏览器打开；或
- 本地静态服务：在项目根执行 `python -m http.server 5177`，访问
  http://localhost:5177/assurance/index.html

## 拓扑（自上而下四层）
1. **高稳智能体**（顶，神经网络图标）—— AI 闭环、用户级根因感知
2. **6 个子网**（虚线框，统一中性描边、选中亮蓝）：其中 **2 个完整**（流量卡 / VIP，各 2 AMF + 2 SMF）、**4 个简化**（各 1 AMF + 1 SMF）。网元用大色点 + 橙/红描边呈现正常/预警/故障
3. **SRF 分发层**（分发树图标）—— 最优恢复策略下发
4. **UE 用户终端**（底，手机图标）

五类语义箭头：子网 → 高稳智能体（上报 KPI/CHR/状态/用户行为）、UE → SRF（用户接入）、UE → 高稳智能体（用户建模）、高稳智能体 → SRF（根因感知）、SRF → 子网（最优恢复策略，指向当前选中用户所在子网）。

## 用户感知面板
- 用户名为**类型化非真名**（VIP 终端 / 流量终端 / 巡检机器人 等），头像为**终端/机器人图标**
- 选择用户后可看到：所属子网、签约、活跃会话、时延；接管的 AMF / SMF 及健康状态；业务成功率、流量、业务发起数三条曲线（近 1h / 24h 切换）；主动保障记录
- 业务成功率曲线：正常用户高位平稳，仅"被保障"用户出现一次明显跌落
- 拓扑中该用户的子网框、接管网元、端到端保障链路同步高亮，其余降淡
