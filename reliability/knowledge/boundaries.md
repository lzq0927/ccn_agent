# 模型与证据边界

本模块归属 ReMAP → AI 系统 → 可靠性机制设计与仿真。当前可执行模型是
5GC 消息级离散事件模型，来自 ccn_agent develop，支持 A–G 合成场景。
它用于研究智能保障系统中的隔离、重选、准入和退避机制。

机制设计、仿真验证、线上部署是三个不同活动。MCP 工具只操作本地实验，
没有向真实网络下发策略的能力。知识库中 implemented 表示代码已实现，
synthetic 表示合成模型或输入；两者都不能直接证明产品已通过验证。

每次实验先生成正常段和故障段，然后从相同仿真状态复制无机制基线与候选方案，
在相同观测窗口内继续推进。机制会改变随机数消费顺序，因此不声称整个恢复段
逐事件使用共同随机数。多种子结果报告样本数、逐种子值和均值；未提供总体置信区间。

成功率来自引擎 12 tick 滚动窗口；最终成功率是各种子的末窗比值均值，不是请求量
加权总体成功率。CPU 是全部核心网元（不含 gNB）的最大值。恢复时间是连续达标
窗口的确认时间，未达标为 null；最后窗口再次失败时 final_target_met 仍为 false。
流控可能减少负载并拒绝服务，必须同时阅读 admission_rejects 与 backoff_rejects。
这些末窗计数不能跨 tick 累加为总损失。成功率/恢复比例不是年度可用度、MTBF 或 MTTR。

现有诊断 Skill 位于 skills/core、skills/workflows 和 skills/exploration，作为领域参考。
原三 Agent 和 LIVE 演示属于兼容入口。新默认编排由 OpenCode 与原生 Skill 执行，
不会嵌套调用旧 LLM Agent Loop。AI 训练/推理专用仿真器、外部知识库连接和直接嵌入
ReMAP 主仓库的菜单尚未实现，需要相应适配与独立验收。
