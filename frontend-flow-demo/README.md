# 高稳智能体 · 方案流程演示前端(`frontend-flow`)

面向"方案讲解"的演示前端,独立于 `frontend/`(API 调试)与 `frontend-show/`(数字孪生沉浸式)。

**两栏布局,自动循环播放**:
- **左侧「方案」(抽象)**:上=方案架构(网络侧 UE/gNB/核心网 ↔ 双向桥 ↔ 高稳智能体[3 Agent + MessageBus + Storage]),下=**诊断闭环**(6 步主干 + 底部显著回流弧 ⑥→① = 清晰循环 + 内层探索回环)。**只画抽象方案,不写具体案例**;当前相位高亮位置。
- **右侧「现场运行 · LIVE TOPOLOGY」(拓扑为主 · 全弹窗)**:数字孪生拓扑**常驻占满全面板(恒定尺寸,消除"忽大忽小")**;关键信息全部以弹窗方式呈现——诊断详情(异常初筛 / CHR 用户级根因 / 均质化比较 / 隔离)直接锚定拓扑节点渲染,右上浮动 PhasePopup 承载当前阶段关键指标/摘要,底部一条当前相位引导条。
- **降色**:相位 8 色彩虹收敛为 4 色族(青绿/青/琥珀/绿),时间轴状态化(accent 为主),拓扑基线降噪、颜色只用于突出焦点;执行过程用脉冲圆点 / 流动小点 / 浮层指针引导。

场景选择只在顶栏。引导元素借鉴 AWS DevOps Agent 互动演示,但**全部自动推进,无需点击触发下一步**。

## 快速开始

```bash
cd frontend-flow
npm install
npm run dev        # → http://localhost:5175  (自动循环播放)
```

构建 / 类型检查:

```bash
npm run build      # tsc --noEmit && vite build  → dist/
npm run lint       # tsc --noEmit
```

> **纯 DEMO 模式**:内置取自真实 `storage/cases` 的样本数据,确定性自动播放,**不依赖后端 / LLM**,展会现场 100% 可靠。无 LIVE 模式。

## 操作

- **播放/暂停 ❚❚ / ▶** · **变速 0.5× / 1× / 2×**
- **底部时间轴**:点击任意阶段跳转;白色播放头显示全局进度,自动循环
- **右侧「现场运行」**:拓扑常驻占满 + 全弹窗(节点锚定诊断弹窗 / 右上浮动 PhasePopup / 底部引导条),随相位自动切换(稳态/KPI 双线/置信度/推理链/恢复/评估),8 相位全覆盖
- **场景选择**:只在顶栏(TopBar)切换 A/B/C,不在右栏重复

### 双 loop(左侧高稳智能体内,体现「闭环」)

- **内层探索 loop(下方)**:◇置信度 低/未收敛 → 探索区 → 回 ③异常检测重检。B/C 场景点亮,逐轮揭示「采什么数据 · 用什么方法 · 是否收敛」:
  - B(技能引导,0.55):1 轮 —— CHR 历史 → 降噪排除终端噪声 → 收敛 5GSM#37
  - C(自主探索,0.28):2 轮 —— CHR 聚类(未收敛)→ 用户分群追踪(gNB_2 物联终端 52%,收敛)
- **外层沉淀 loop(上方)**:⑥评估 →「Skill 沉淀 · 难例回流」→ 回到主干起点(phase 7 点亮)。A3 评估后把优化建议/新难例回流给 A1/A2,形成系统闭环。

### 嵌入式流程图与探索回环(左侧高稳智能体内)

固定 6 步主干始终可见,从「◇置信度判定」分两路:

- **右出(高 / 收敛)** → ④根因 → ⑤恢复 → ⑥评估 —— A 场景(置信度 0.76 > 0.7)走此路,直达。
- **下出(低 / 未收敛)** → **探索回环区** → 回到 ③异常检测重检 —— B/C 场景点亮,逐轮揭示「采什么数据 · 用什么方法 · 是否收敛」:
  - B(技能引导,0.55):1 轮 —— 采集终端原因值持续周期性 CHR 历史 → CHR 降噪排除既有噪声 → 收敛 5GSM#37
  - C(自主探索,0.28):2 轮 —— ① CHR 聚类去散点(仍分散未收敛)→ ② 用户分群追踪(gNB_2 物联终端群体 52% 失败,收敛)

### 嵌入式流程图与探索回环(左侧高稳智能体内)

固定 6 步主干始终可见,从「◇置信度判定」分两路:**右出(高/收敛)→④根因**(A 直达)、**下出(低/未收敛)→探索回环→回③重检**(B/C 点亮)。详见上文「双 loop」。

## 方案流程 8 阶段(确定性自动循环)

| # | 阶段 | 方案描述(左) | 方案运行·侧栏(右,全相位覆盖) |
|---|------|----------|------------------|
| 0 | 网络就绪 | 全网稳态,逐链路监测待命 | SR 仪表 + KPI 基线 |
| 1 | 数据采集 | Agent 1 现网采集遥测,LLM 多维校验闭环 | 5 项校验灯 + 入库进度 |
| 2 | 异常检测 | CHR + KPI 双线并行,任一检出即触发 | KPI+CHR 双线图 + 异常链路 |
| 3 | 策略匹配 | 多维特征加权评分,置信度三路径分流 | 置信度分解条 + 路由徽章 |
| 4 | 根因推理 | Agent Loop 推理链收敛,定位根因 | 推理链逐步揭示 |
| 5 | 执行恢复 | 下发恢复策略,网络自愈 | 恢复动作序列 + 隔离围栏 |
| 6 | 网络恢复 | 成功率回升,闭环验证 | SR 回升仪表 + KPI 曲线 |
| 7 | 评估优化 | Agent 3 比对真值,优化建议回流(外层 loop) | P/R/F1 + 推理质析 + SkillLibrary |

## 引导元素(自动版,借鉴 AWS 互动演示)

- **节点态**:已完成 = 该步色淡填充 / 当前 = 该步色实心 + 脉冲环 + 发光 / 未到 = 空心暗淡
- **流动虚线**:主干连接线与回环弧用 `flow-dash` / `flow-dash-rev` 流动,标示数据/探索方向
- **双向桥**:核心网 ↔ 高稳智能体,数据下行(phase≥1)与指令上行(phase 5-6)双向流动粒子
- **网络脉冲**:受影响 NE 在异常相位脉冲(核心网 single_ne 红 / 场景 C gNB 琥珀用户级)
- **探索回环**:◇置信度「低/未收敛」分支点亮回环区,B/C 逐轮浮出探索卡片(采什么 · 用什么 · 是否收敛)

## 默认场景

固定 **场景 A · 核心网 UPF 异常 · 确定性工作流**(置信度 0.76 > 0.7 → WORKFLOW):前端 AMF↔SMF 路径均质化异常排除 AMF/SMF,UPF 故障聚合定位 UPF_1,隔离后流量切至 UPF POOL。

## 技术栈

React 18 + TypeScript + Vite 5 + Framer Motion。流程图为 div + Framer Motion(节点高亮过渡、圆点脉冲、粒子流动、气泡进出),复用 `frontend-show` 的确定性时钟导演(`story/director.ts` + `useStoryClock.ts`)、场景数据与阶段面板。
