## 回归覆盖

- 40 分钟正常背景噪声不确认告警；两个分钟尖峰虽有候选异常，也不满足 4/5。
- 不同维度各自发生单次尖峰，不被合并成持续告警。
- 更换为 SMF:smf_1 故障及随机种子 7、2026，定位随数据变化。
- 截断未来数据后，T+24 的感知、流程、聚类、推理、拓扑、交接与完整数据的因果前缀一致。
- 持续高频 DNN 背景不进入异常结果；保留记录均属于已确认维度的异常分钟。
- 中文/英文别名、前导零 IMSI、无效行、缺失可选字段、表头空文件、跨文件重复处理。
- 六类文件、双实例、60 条类型间 full-mesh 逻辑边。
- Trace 关联分离不同流程；无 Trace 的关联为候选，同时间重复源标记为歧义。
- BH 校正、POD 显著性、分散的用户/基站/区域不错误标记、用户粒度二次分析实际可触发。
- 未知原因码、多个充分匹配、仅超时缺少重传机制证据进入未执行的慢推理待办。
- 使用图谱 `signals` 把 SIM 码替换成 VENDOR 码，仍可得到同一定位。
- 偶发少量后端超时不扩大故障链路范围；候选恢复路径实际来自拓扑。
- API 参数边界、SSE 日志与结果、有限数值 JSON、Markdown/JSON 下载。
- UI 时间确认边界、时序选择、六维证据、用户搜索/展开、知识码切换、交接下载、正常实验、重新加载与窄屏导航。
