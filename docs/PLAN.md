# CHR 故障感知与分析实施计划

基础分支：`main-chr-gpt`，基础提交：`419d94d40a938339194e89ebbc1cf1f535127cf4`。分支仅有 README，无历史实现或上传的实验室数据。

1. 调研公开 5GC 协议原因码和可视化能力；定义标准码、模拟内部码、可替换数据边界。
2. Python 仿真输出每类网元一个 CSV、双实例双 POD、类型间 full mesh 拓扑和独立实验真值。40 分钟、秒级 CHR，T+20 注入。
3. FastAPI 提供预处理、每分钟 15 分钟滚动检测、同维度 4/5 确认、降噪、用户级流程重建。
4. Fisher 单侧检验、BH 多重检验校正、效应量和支持度完成六维显著性分析；无结论时按用户重新分析。
5. JSON 知识图谱保留一对多场景、证据要求、替代解释；交叉验证输出结论或进入待接入的慢推理工具计划。
6. React + TypeScript + ECharts 白底工作台：工作流、可交互拓扑、时序、饼图、散点图、用户路径、知识图谱、真实事件日志、报告下载。
7. 后端回归、构建及浏览器回放验证；补齐内网替换、启动、算法限制和 API 说明。

不实现决策执行。结构化交接只在本地生成/下载；慢推理接口不伪装为已经调用 Agent 或探测工具。
